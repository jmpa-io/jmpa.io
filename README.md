# `jmpa.io`

```diff
+ 🚪 The front door: one simple page linking to everywhere I live online.
```

`jmpa.io` is a small, dark, Fira Code page: a pixel-art Jordan (with two pixel budgies) at a terminal-style monitor, links
grouped into categories below, and a 3D on-screen keyboard whose keys are the links and a few actions. Link categories
(see `data/links.yml`): Writing & CV (resume, blog), Code (GitHub, jmpa-io), Art, Work & projects, Tools.

The old Windows 98 desktop / CRT / pixel-room versions are gone from the tree (they are in git history).

## Adding or changing a link

Everything is data-driven from `data/links.yml`: the category cards, the link keys on the keyboard and the footer icons all read it.
Add a link under an existing category, or add a whole category:

```yaml
categories:
  - id: code                      # anchor / aria id
    title: Code                   # section heading
    blurb: Where the source lives.
    links:
      - name: GitHub              # card title
        url: https://github.com/jcleal
        desc: Personal projects.  # one line (quote it if it contains a colon)
        icon: github              # icon name (partials/jmpa-icon.html)
        key: git                  # legend on its keycap (<= ~5 chars); each link becomes one F-key in order
        external: true            # target=_blank rel="noopener noreferrer"
footer:                           # footer icon links (name, url, label, icon, external)
```

A category with no links fails the e2e. Page copy (eyebrow, heading, sub text, footer tagline) is in `config.yml` under `Params`.
`config.yml` also limits `module.mounts` to the files this site uses, so stray local files can't break the build.

## The pixel scene and keyboard

- Sprites are PNGs in `static/img/` (`person.png`, `budgie-green.png`, `budgie-blue.png`, `props.png`), generated by
  `python tools/gen_sprites.py` (Pillow). Jordan is hand-drawn in `tools/jordan_art.py` (56x64, one text row per pixel row, drawn from a
  caricature reference that is not embedded; `python tools/jordan_art.py sheet.png` renders the reference beside the candidates).
  Sprites are `<div>` sprite sheets, `image-rendering: pixelated`, integer upscales, stepped (`steps()`) animation, a static frame
  under `prefers-reduced-motion`. There are no SVG birds.
- The hoodie is the one approved 18x18 hoodie (A18, from `art.jmpa.io`). `python tools/gen_icons.py` generates the nav logo
  (`hoodie-18.png`), favicons, apple/android icons and the three `share-v*.png` images from it. 16px/32px favicons are non-integer
  nearest-neighbour scales; the rest are integer scales.
- The monitor (`jmpa-screen.html`) is static: name, tagline and link list, plus an echo of the last key pressed. Nothing types by itself.
- The keyboard (`jmpa-keyboard.html`, `static/css/keyboard.css`, `static/js/keyboard.js`) has raised 3D keycaps. F1.. keys are the links; action
  keys switch theme, make the flying budgie fly, switch the screen page, show help, and home. It is **pointer/touch only**: it never
  listens to the physical keyboard (no keydown/keyup handlers, no preventDefault). Keys are real `<a>`/`<button>` elements, so Tab, Enter and
  Space work the browser-default way. It can be hidden (header toggle, remembered in `localStorage['jmpa-kb']`).
  Caveat: the mirrored `palette.js` has its own Escape-to-close handler for the colour popup.
- Everything uses self-hosted, latin-subset [Fira Code](https://github.com/tonsky/FiraCode) 400 and 700
  (`static/fonts/firacode-*.woff2`, SIL OFL: `static/fonts/FiraCode-OFL.txt`), `font-display: swap`. `font-src 'self'` holds.
- Security: the CSP is a `<meta>` tag in `jmpa-head.html` (`script-src 'self'`, no inline script/style, so the page's
  setup lives in `static/js/init.js`); the headers a meta tag can't set (HSTS, nosniff, frame, referrer, permissions)
  come from the `SecurityHeaders` response headers policy in `cf/website/template.yml`.
- No OpenTelemetry: this is a static page with no server code of its own, so there is nothing to trace; the CDN access logs
  already cover traffic, and browser telemetry would add a third-party-style beacon (CSP `connect-src 'none'`) for no gain.

## Colours and day/night

The header has a colour picker (Primary + Secondary, plus Reset) and a sun/moon toggle. **The default scheme is dark**, and the
default pair and look come from the theme variant: `params.variant` in `config.yml` (1 midnight terminal, 2 deep ocean,
3 blueprint; `?v=1|2|3` previews another without persisting). Change that one value to pick the default. `static/js/init.js`
holds each variant's default pair (passed to `Palette.init({ defaults })`; Reset returns to it); the variants' `--v-*` tokens
in `static/css/site.css` apply only until a visitor picks their own colours (`html[data-custom]`), then the picker's derived colours take over.
Contrast stays AA in light and dark. Choices persist in `localStorage` (`palette-custom`, `scheme`) and apply before first paint.

`static/js/palette.js` and `e2e/{playwright.config.ts,helpers/palette-helpers.ts,server.mjs}` are mirrored masters from
`jcleal.me` - do not edit them here (`make e2e-sync` in `jcleal.me`). The per-site default lives in `e2e/site.ts`.

## Running locally?

1. Using a <kbd>terminal</kbd>, run:
```bash
make serve
```

2. Using your browser, navigate to `localhost:1314`.

## Testing

Playwright tests live in `e2e/` (system Chrome; nothing is downloaded, external requests are blocked):

```bash
make generate-website                       # builds into dist/public
make e2e                                    # npm ci + playwright test against dist/public
cd e2e && npm run test:update               # refresh baselines (delete the snapshot dir to force a full regen)
```

Specs: `categories` (headings, hrefs, no empty categories, a11y), `keyboard` (3D keys, link/action keys, pixel sprites and no SVG birds,
physical keyboard ignored with no preventDefault, overflow at 390/768/1280/1600, contrast, CSP),
`colours` (default pair, Reset, picker, AA sweep, scheme toggle), `states` (hover/focus-ring contrast across the colour sweep),
`security` (CSP, no inline script/style, nothing trips it), `footer` (alignment at 5 widths, AA, baselines) and `github`
(GitHub mark on the GitHub link). `E2E_PORT=<port>` moves the test server off 4172 (build with a matching `--baseURL`).
